# Architecture & Features Specification: Spatial Reflection & Reverb Module

This document outlines the initial architectural and design specification for a VCV Rack module that models 2D geometric acoustic spaces. The module calculates real-time early reflections via the Image-Source method based on CV-controlled source, listener, and wall boundaries, feeding a traditional late-reverb tail network.

---

## 1. Core Architectural Overview

The module uses a **hybrid DSP architecture** to balance physical modeling accuracy with audio-rate CV responsiveness, avoiding the high CPU overhead of real-time convolution.

## 2. Parameter & CV Interface Matrix

All geometric properties are fully addressable via standard Eurorack control voltages (-5V to +5V or 0V to 10V, scaled internally to the 2D canvas coordinates).

| Parameter Group | Interface Element | CV Input | Description |
| --- | --- | --- | --- |
| **Spatial Coordinates** | $X/Y$ Joystick / Knobs | `X IN`, `Y IN` | Controls the coordinates of the Sound Source ($S$) and Listener ($L$) within the 2D bounding box. |
| **Room Boundaries** | 4x Independent Knobs | `LEFT`, `RIGHT`, `TOP`, `BOTTOM` | Modulates the positions of the 4 perpendicular walls relative to the center origin $(0,0)$. |
| **Acoustic Material** | 4-Position Switch / Attenuverter | `MAT CV` | Selects or morphs the reflection material profiles across all walls simultaneously or per-wall. |
| **Late Reverb Control** | Decay / Mix Knobs | `DECAY CV`, `MIX CV` | Adjusts the RT60 decay time and dry/wet balance of the dense reverberant tail. |

## 3. DSP Engine Specification

### 3.1 Early Reflections (Image-Source Model)

The module calculates 4 virtual source positions ($S'$) generated by mirroring the source coordinate $S = (x_s, y_s)$ across the dynamic wall boundaries ($W_{left}, W_{right}, W_{top}, W_{bottom}$).

* **Delay Computation:** Calculated using Euclidean distance from the listener $L = (x_l, y_l)$ to each virtual source:

$$\text{Distance} = \sqrt{(x_l - x_{s'})^2 + (y_l - y_{s'})^2}$$


$$\text{Delay (samples)} = \frac{\text{Distance}}{\text{Speed of Sound}} \cdot \text{Sample Rate}$$


* **Buffer Interpolation:** Implements **Cubic Hermite Spline interpolation** for the delay-line read pointers to ensure smooth, artifact-free pitch modulation (Doppler effect) during fast CV movement.
* **Slew Management:** Internal low-pass filters (slew limiters) damp incoming coordinate CV to simulate physical inertia and control extreme pitch bending.

### 3.2 Material Filter Profiles

Each wall tap is routed through an independent filtering stage determined by the selected material preset. This changes the high/low frequency absorption coefficient ($\alpha$).

```
                +---------------------------------------+
                |        Raw Delay Tap Output           |
                +---------------------------------------+
                                    |
                                    v
                       +-------------------------+
                       |  Low-Pass/High-Cut Link | <--- High frequency absorption
                       +-------------------------+
                                    |
                                    v
                       +-------------------------+
                       |    Attenuator / Gain    | <--- Overall Surface Reflection Loss (1 - α)
                       +-------------------------+
                                    |
                                    v
                       +-------------------------+
                       |  To Spatialization Matrix|
                       +-------------------------+

```

* **Metal:** $\alpha \approx 0.05$ (Flat EQ response, maximum gain preservation).
* **Wood:** $\alpha \approx 0.15$ (Subtle low-pass filtering, dampens harsh transients).
* **Foam/Carpet:** $\alpha \approx 0.75$ (Aggressive low-pass filtering, highly attenuated gain).
* **Concrete:** $\alpha \approx 0.01$ (Total reflection, complete high-frequency preservation).

### 3.3 Late Reverb Tail

* A classic 4- or 8-channel **Feedback Delay Network (FDN)** handles dense, isotropic diffuse decay.
* Inputs to the FDN are derived from the late reflections of the multi-tap system to preserve spatialized room-size energy distribution.

## 4. User Interface & Graphical Render Spec

The faceplate features an integrated, real-time visual display driven by NanoVG vector graphics inside the VCV Rack framework.

```
+-------------------------------------------------+
|  [O] IN L   [O] IN R               SPATIAL REVERB  |
|                                                 |
|  +-------------------------------------------+  |
|  |  W_top Line (Dynamic)                     |  |
|  |  +-------------------------------------+  |  |
|  |  |                                     |  |  |
|  |  |     • S (Source Node)               |  |  |
|  |  |                                     |  |  |
|  |  |                   • L (Listener)    |  |  |
|  |  |                                     |  |  |
|  |  +-------------------------------------+  |  |
|  |  W_bottom Line                            |  |
|  +-------------------------------------------+  |
|     Visual 2D Feedback Display Canvas           |
|                                                 |
|     (O) X-CV    (O) Y-CV    (O) WALLS-CV        |
|     [O] OUT L   [O] OUT R                       |
+-------------------------------------------------+

```

* **Dynamic Bounding Box:** Renders a 4-sided wireframe rectangle visualizing the current positions of $W_{left}$, $W_{right}$, $W_{top}$, and $W_{bottom}$.
* **Material Signifiers:** The perimeter lines dynamically shift color/texture based on the current material coefficient (e.g., glowing white for metal, matte brown for wood, dark gray for foam).
* **Positional Nodes:**
* **Source Node ($S$):** A glowing vector dot tracking audio input spatialization.
* **Listener Node ($L$):** A secondary color vector dot representing the stereo center point of the listener.

## 5. Implementation Milestones

1. **Phase 1: Math Validation & Core DSP:** Write the basic C++ circular buffer class utilizing 4 dynamic read pointers governed by static geometric calculations.
2. **Phase 2: Signal Conditioning:** Integrate cubic interpolation for the read pointers and implement variable coefficient filters for the material simulation.
3. **Phase 3: VCV Ecosystem Integration:** Map the hardware-level UI parameters to the parameters engine (`rack::engine::Param`) and map the inputs to the input engine (`rack::engine::Input`).
4. **Phase 4: Widget Implementation:** Code the NanoVG custom widget to draw the moving room architecture and nodes in synchronization with audio-rate processing.
