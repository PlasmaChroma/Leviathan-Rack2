Lubadh v2.1.0

Preset Editor [ about ]

The Lubadh now features user-configurable presets. Each deck of Lúbadh can independently toggle between two active presets. A preset folder on the USB drive contains a file called PresetLoader.txt which can be used to select the active presets. The preset folder is also populated with a selection of factory preset files to get you started. Within the PresetLoader.txt file, insert the name of the desired presets within the quotation marks next to “PresetA:” and “PresetB:”

Presets are curated, edited, and accessed via the USB drive. Edits made to any of the preset files will be saved between power cycles. To revert a preset back to the factory settings, delete it and a fresh copy will be recreated upon power up. Keep in mind that they’re just text (.txt) files - Edit them, rename them, play with them, and share your favourite settings with the community.

To toggle between presets on deck 1, press and hold the Retrigger/Shift Buttons of deck 1 and deck 2, then press the Erase Button of deck 1. This action is mirrored for toggling between presets on deck 2.

Once you have finished making alterations, click on Generate Configuration, scroll down to review the parameters and values and once happy with changes, click Download Lúbadh preset file.

Lúbadh V2.1 uses a new method of loading preset files.

Factory presets and user created presets can be copied into the folder named presets. By default this folder will be empty. Once filled with preset files, a new preset selection menu can be accessed on Lúbadh by pressing and holding both Shift/Retrigger buttons and the Erase button of the corresponding deck.

Up to 12 presets can be loaded via the preset selection menu, but as many presets as memory allows can be stored on the USB. Preset files in this folder will be sorted alphanumerically. With this in mind, factory presets have a 01, 02, 03... 12 prefixed naming convention for clear loading. We would recommend any user created presets also follow this naming convention.

Once in the preset selection menu, the first 12 alphanumerically sorted preset files are represented by LED segments around the relating to their 1-12 position. Use the Time Pot on the corresponding deck to select from up to 12 of these locations. Pressing Record will load the preset. If you wish to cancel, press Erase to exit the preset selection menu.
