[ about ]

arbhar's user interface has been developed with live performance in mind, giving direct and immediate control over all parameters of the granular playback engine. However, there are various audio-processing parameters, as well as control approaches, that might not need immediate influence. Nevertheless, these parameters allow for changes to arbhar's configuration that will enable particular workflow and performance approaches.

This preset configuration tool outlines these parameters in the [ details ] drop-downs, that give an overview of the possible parameter settings.
In order to generate the configuration and saving the preset file to use with the arbhar, ensure to generate the code at the bottom of this page and to download the preset file.

Please note that a valid arbhar preset file has to have the #ARB identification at the beginning of the file (identical to the identification at the top of this file).

Some parameters are accessed via button and knob combinations. These button and knob combinations will be referred to as PARAM_TEMPORARY throughout this configuration file.
