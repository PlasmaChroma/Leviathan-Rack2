Once you have finished making alterations, click on Generate Configuration, scroll down to review the parameters and values and once happy with changes, click Download arbhar preset file.

To load the preset file into arbhar there are two options:

  • First, by placing the newly downloaded text file in a _arbhar_scenes folder of your choosing, and use the LOAD SCENE menu on arbhar.
    Enter the CLONE, LOAD, SAVE menu by pressing SHIFT, CAPTURE and STRIKE, then select the scene you would like to load and confirm your selection with double pressing SHIFT.
  • Alternatively, arbhar is also capable of loading any custom behaviour via a preset file named preset.txt found in the root directory of the USB drive.
    Entering the CLONE, LOAD, SAVE menu by pressing SHIFT, CAPTURE and STRIKE, then immediately exiting via the same button combo will automatically load this "preset.txt" named file.

Please note: The file preset.txt will be renamed to preset_wasLoaded.txt after loading! This is to prevent unintended loading of the same file after further user interaction on arbhar.
